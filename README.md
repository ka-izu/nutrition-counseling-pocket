# 栄養指導ポケット
## サービス概要
栄養指導ポケットは、
限られた時間・限られた患者情報の中で即時対応を求められる調剤薬局の栄養士に向けた、
栄養指導ナレッジの管理と、患者特性に応じたクイックアドバイスを提供する栄養指導支援ツールです。

疾患別の食事療法ガイドや指導媒体を一元管理できるほか、
患者の疾患・生活習慣・性格傾向といった情報をもとに、
「今日、この患者さんにどう伝えるか」を判断するための一言アドバイスを提案します。

指導の場での判断を補助し、
栄養士が本来注力すべきコミュニケーションに集中できることを目的としています。
## このサービスへの思い・作りたい理由

私は、調剤薬局で管理栄養士として栄養指導に携わってきました。
調剤薬局での栄養指導は、
患者の薬の受け取り中や短い待ち時間など、限られた時間の中で行われることが多くあります。
また、病院とは異なり、検査データや食習慣・生活習慣といった情報が十分に揃わない状態から指導を始めるケースが少なくありません。
そのような状況でも、患者一人ひとりの状況に合わせた指導が強く求められます。

しかし実際には、
- 十分な患者情報が得られないため事前準備が難しく、その場対応になりやすい

- その場対応になりやすいがゆえ、準備した指導資料を十分に活用できず、患者にとって納得感のある情報提供が難しい

- 限られた時間の中で、患者の状態・特性を把握し、「どう伝えるか」を判断することにはスキルを要し、栄養士にとって大きな負担になる

といった課題があります。

本サービスは、限られた時間・限られた情報の中でも、
患者一人ひとりの状況に合わせた情報を伝えるためのサポートとして、
栄養士の指導を補助することを目的に企画しました。

## ユーザー層について

- 調剤薬局・クリニックで栄養指導を行う管理栄養士・栄養士

## サービスの利用イメージ
1. 栄養士がログイン
2. 目的に応じて以下を選択
- ナレッジを見る
  

  疾患別の食事療法ガイド、指導媒体を確認

  ※ 本アプリの食事療法ガイドは、各専門学会が公表している治療ガイドラインを参考に、一般的な情報としてまとめたものです。

- クイックアドバイス
  
  疾患・生活習慣・性格傾向などを選択し、一言アドバイスを確認

  アドバイス内容の例：
    - 高血圧 × 外食多め × めんどくさがり

      → 「外食のときは、汁を残すだけで塩分を約2g減らせます。今日はそれだけ意識できれば十分です」

  ※ 本機能は、何かを診断するものではなく、患者が気軽に「やってみようかな」と感じられるレベルのアドバイスを提供します（プロンプトで出力内容を制御）。また、サービスのユーザーは栄養士であり、提供されたアドバイスが指導の補助的位置付けであることをUI等で示します。

- ナレッジを管理
  
  - 食事療法ガイドの管理
  
    食事療法の基本指針を確認できる他、メモ機能を備えており、ガイドプラスαで伝えたいことや、指導の際に注意すること等を自分用に編集・追記できる。

  - 指導媒体の管理
  
    指導に使う媒体を疾患ごとに管理できる。タグによる検索が可能。

## ユーザーの獲得について

- 知人の栄養士や、専門外の方にも「もし使うとしたらどう感じるか」という視点で使ってもらう

## サービスの差別化ポイント・推しポイント
栄養指導ポケットは、食事記録や栄養分析を行う一般ユーザー向けアプリとは異なり、
栄養指導を行う側である栄養士の判断や伝え方を支援することに特化したツールです。

| サービス | 特徴 | 差別化ポイント |
|----------|------|----------------|
| あすけん | 一般ユーザー向けのダイエット・健康管理支援サービス。食事記録からカロリーや栄養素を自動計算 | **栄養士向け**の指導支援サービス。媒体管理・ガイド参照・クイックアドバイスで食事指導を支援 |
| カロミルアドバイス | 栄養士、指導者向け食事指導支援サービス。食事 / 身体データを一元管理、記録にもとづくAIアドバイスあり | 媒体管理やガイドのメモ機能を通じて、**指導者自身のナレッジ**を蓄積・管理。それにより、**自分専用の指導手引**を作成できる |

**推しポイント**
- 「栄養士向け」に特化したナレッジ管理
  
  疾患別に食事療法ガイドや指導媒体を一元管理できます。
これにより、日常業務の中で蓄積される知識を、すぐに取り出せる形で整理できます。

- 患者特性に応じた "伝え方" のクイック提示
  
  疾患・生活習慣・性格傾向などを選ぶだけで「一言アドバイス」を提案します。
患者一人ひとりに合わせた伝え方をサポートします。

- 公的ガイドラインをベースにした指導サポート
  
  公的ガイドラインに準じた食事療法の基本指針をテンプレートとして登録しています。
  指導時に「何を伝えるべきか」を素早く確認でき、現場での迷いや不安を軽減します。
  メモ機能を備えており、編集・追記しながら自分専用の栄養指導手引として活用できます。

## 機能候補
### MVPリリース時

- ユーザー登録 / ログイン / ログアウト
- 食事療法ガイドの閲覧
- 指導媒体（画像データ）の閲覧・編集
- クイックアドバイス機能
  
  疾患・生活習慣・性格傾向などを選択し、AIによる一言アドバイス生成
- 指導媒体検索機能（タグによる検索を予定）

### 本リリースまでに作りたい機能（案）
- 食事療法ガイドのメモ機能追加
- 食事療法ガイドをユーザーが独自に作成できる機能
  
  本サービスが提供するガイドでは網羅できていない疾患について、ユーザー自身がガイドラインを整理し、追加できる。
- 指導媒体のお気に入り登録
- オートコンプリート

## 使用する技術スタック
現時点で考えているものです。今後の実装フェーズで変更の可能性があります。

#### 言語・フレームワーク

- Ruby 3.2
- Ruby on Rails 7.2.2
  
  Railsの標準機能（認証、CRUD、Active Storageなど）を活用

#### フロントエンド

- TailwindCSS

#### 外部サービス・API

- （予定）Gemini API（一言アドバイス生成）
  
  患者個人を特定しない一般化された条件（疾患・生活習慣・性格傾向など）をもとに出力する設計を予定

#### インフラ・ストレージ

- Render（デプロイ先）
- Neon（データベース）
- （予定）Active Storage + Cloudflare R2（画像の保存）
